### **Historia 6: Páginas Estáticas**

**Como** administrador  
**Quiero** tener páginas estáticas editables  
**Para** mostrar información sobre mí y contacto

**Descripción detallada:** Sistema de páginas estáticas simples con editor básico para contenido institucional.

**Criterios de aceptación:**

- 6.1 Página "Sobre mí" editable desde admin
- 6.2 Página "Contacto" editable desde admin
- 6.3 Editor simple (sin necesidad del editor completo de posts)
- 6.4 URLs amigables: /{locale}/about, /{locale}/contact
- 6.5 Soporte multiidioma para páginas estáticas
- 6.6 Meta tags personalizables por página
- 6.7 Posibilidad de agregar nuevas páginas estáticas
- 6.8 Preview de páginas antes de publicar
