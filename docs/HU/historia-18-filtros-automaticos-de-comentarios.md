### **Historia 18: Filtros Automáticos de Comentarios**

**Como** administrador  
**Quiero** filtros automáticos para comentarios  
**Para** reducir spam y contenido inapropiado sin intervención manual

**Descripción detallada:** Sistema inteligente de filtrado automático de comentarios usando múltiples técnicas de detección de spam.

**Criterios de aceptación:**

- 18.1 Integración con Akismet para detección de spam
- 18.2 Filtro de palabras prohibidas configurable
- 18.3 Detección de enlaces excesivos
- 18.4 Rate limiting por usuario/IP más estricto
- 18.5 Machine learning básico para patrones de spam
- 18.6 Auto-rechazo de comentarios con alta probabilidad de spam
- 18.7 Quarantine para comentarios dudosos
- 18.8 Whitelist automática para usuarios frecuentes
- 18.9 Reporting de falsos positivos/negativos
- 18.10 Dashboard de efectividad de filtros
