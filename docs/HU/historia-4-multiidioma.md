### **Historia 4: Multiidioma**

**Como** visitante internacional  
**Quiero** leer el blog en mi idioma preferido  
**Para** tener una mejor experiencia de usuario

**Descripción detallada:** Sistema multiidioma completo con detección automática, URLs localizadas y SEO optimizado para cada idioma.

**Criterios de aceptación:**

- 4.1 Soporte para español (idioma por defecto), inglés y portugués
- 4.2 URLs localizadas: /{locale}/... para cada idioma
- 4.3 Detección automática del idioma del navegador
- 4.4 Selector de idioma visible en header
- 4.5 Traducción de interfaz de usuario completa
- 4.6 Posts traducibles por idioma
- 4.7 Meta tags hreflang correctos para SEO
- 4.8 Sitemap separado por idioma
- 4.9 Canonical URLs por idioma
- 4.10 Fallback a español si traducción no existe
