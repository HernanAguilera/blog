### **Historia 8: SEO y Performance**

**Como** visitante  
**Quiero** una experiencia rápida y optimizada  
**Para** navegar cómodamente el blog

**Como** administrador  
**Quiero** que mi blog esté optimizado para buscadores  
**Para** aumentar mi visibilidad online

**Descripción detallada:** Optimizaciones técnicas para SEO y performance siguiendo mejores prácticas web.

**Criterios de aceptación:**

- 8.1 Meta tags dinámicos por página/post
- 8.2 Open Graph tags para redes sociales
- 8.3 Sitemap automático generado por Nuxt
- 8.4 URLs amigables en todo el sitio
- 8.5 Canonical URLs correctas
- 8.6 Optimización de imágenes automática
- 8.7 Critical CSS inline (automático con Nuxt)
- 8.8 Cache de archivos estáticos
- 8.9 Compresión gzip habilitada
- 8.10 Score Lighthouse > 90 en todas las métricas
