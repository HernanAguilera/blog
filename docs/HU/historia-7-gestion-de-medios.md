### **Historia 7: Gestión de Medios**

**Como** administrador/colaborador  
**Quiero** gestionar archivos multimedia  
**Para** enriquecer el contenido del blog

**Descripción detallada:** Sistema completo de gestión de archivos con upload a AWS S3, optimización y organización.

**Criterios de aceptación:**

- 7.1 Upload de imágenes a AWS S3
- 7.2 Tipos permitidos: jpg, jpeg, png, gif, webp
- 7.3 Tamaño máximo: 5MB por archivo
- 7.4 Optimización automática de imágenes
- 7.5 Alt text obligatorio para accesibilidad
- 7.6 Galería de medios en panel admin
- 7.7 Búsqueda de archivos por nombre
- 7.8 Eliminación de archivos no utilizados
- 7.9 URLs públicas para archivos
- 7.10 Integración directa con editor de posts
