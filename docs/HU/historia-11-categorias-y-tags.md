### **Historia 11: Categorías y Tags**

**Como** visitante  
**Quiero** explorar contenido por temas específicos  
**Para** encontrar posts relacionados a mis intereses

**Como** administrador  
**Quiero** organizar mi contenido por categorías y tags  
**Para** facilitar la navegación y descubrimiento

**Descripción detallada:** Sistema completo de taxonomía con categorías jerárquicas y tags libres, incluyendo páginas de archivo y navegación optimizada.

**Criterios de aceptación:**

- 11.1 Categorías jerárquicas (padre/hijo)
- 11.2 Tags libres por post (múltiples tags)
- 11.3 Páginas de archivo: /category/{slug}
- 11.4 Páginas de archivo: /tag/{slug}
- 11.5 Widget de categorías populares
- 11.6 Widget de tag cloud
- 11.7 Posts relacionados por tags (máximo 5)
- 11.8 Breadcrumbs para categorías
- 11.9 SEO optimizado para páginas de archivo
- 11.10 Multiidioma para categorías y tags
